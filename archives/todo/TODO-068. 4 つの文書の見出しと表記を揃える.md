## きっかけ

見出しの階層が分かりにくいという利用者の依頼で、`README.md`・
`docs/Player.md`・`docs/Admin.md`・`docs/Developer.md` の見出しに、
`#` の数と同じ数の `=` を接頭辞として付けることにした（`## == 見出し`）。

あわせて、この 4 文書を wording に点検させた 25 件の指摘のうち、
利用者が選んだ 2 点（Free モードの呼び方の統一、丸括弧の半角統一）も
同じ項目でまとめて直すことにした。

## やったこと

- 4 文書のコードブロック外の見出し（91 個）に、レベルと同じ数の `=` を
  Python スクリプトで機械的に付けた
- Free モードの呼び方を「Freeモード」に統一した。対象は README.md の
  1 箇所と docs/Developer.md の 8 箇所（「free move」「free move モード」
  「ルールを無視して、自由に動かせるモード」）。**ヘッダのチェックボックスの
  名前として書いている「Free」**（docs/Player.md の該当箇所）はそのまま残した
- 丸括弧を全角 `（）` から半角 `()` へ統一した（README.md 0 箇所、
  Player.md 23 箇所、Admin.md 40 箇所、Developer.md 108 箇所）。
  **コードブロックの中の括弧は対象外**とし、機械的な置換で紛れ込んだ
  3 箇所（Admin.md の TOML コメント 1 箇所、Developer.md の mermaid の
  ラベル 2 箇所）は全角に戻した

## 確かめたこと

- 見出しの行すべてに、レベルに応じた `=` が付いていること
  （`#` の直後のマーカーが抜けている行が無いことをスクリプトで確認）
- 文書の中に見出しへのアンカーリンクが無いこと（`](#...)` 形式のリンクが
  4 文書に無いことを確認済み）。GitHub のアンカーは見出しの文字から
  作られるので、外部から見出しへ張ったリンクは切れるが、それは元々の
  依頼どおり許容する
- 「free move」「free_move」の表記が 4 文書から無くなったこと
- 4 文書に全角括弧（`（`・`）`）が残っていないこと（コードブロックの
  中の 3 箇所を除く）
- markdown のリンク・画像の構文（`[text](url)` / `![alt](url)`）が
  括弧の置換前後で件数が変わっていないこと（README.md 19・Player.md 7・
  Admin.md 3・Developer.md 2）
- `git diff` で意図した箇所以外が変わっていないこと

書式を揃えるだけの変更のため、実装と確認は分けず main が行った
（`~/.claude/CLAUDE.md` の「文書や定義ファイルだけを変える項目」の例外）。
