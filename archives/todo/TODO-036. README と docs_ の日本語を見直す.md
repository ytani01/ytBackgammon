## やったこと

### 推敲（wording）

`README.md` と `docs/` の 3 つを読み直し、言い回しだけを直した。
コマンド・手順・リンク・表の事実関係は変えていない。

直したのは、「〜して下さい」の漢字表記、冗長な言い回し、
文末の重なりなど。

**そのうち 7 か所は、管理者が元に戻した。**

| 戻したもの | 理由 |
|------------|------|
| 「おしゃべりしながらご利用ください」 | 利用者が書いた語り口。「お楽しみください」に戻した |
| 「ご使用ください」×2 | 硬い。「お使いください」に戻した |
| 「リロードをしてください」 | 「してみてください」の「みて」は試す意味なので残す |
| 「ポートが使用中」 | 見出しは平易な「塞がっている」のままがよい |
| 「ブラウザから接続できない」 | 同上。「つながらない」に戻した |
| 「`clock_state` として加える」 | `gameinfo` の外に付けるものなので「添える」が正確 |

### `docs/Player.md` の重複を整理（利用者の指摘）

同じことが 3 か所に書かれていた。

- 「画面の見方」の表（番号 1〜8）
- 「ヘッダ」の表と、その下のキャプション（「左から、1 メニュー、2 Sound…」）
- 「盤面」の箇条書き（チェッカー、ダイス、キューブ、ダイスカップ…）

**役割で分けた。**

- 「画面の見方」の表は**どこにあるか**だけ（説明は各節に譲る）
- 「ヘッダ」は画像に番号列を足した表 1 つにまとめ、重複するキャプションを消した
- 「盤面」の箇条書きは消し、ほかに書いていないこと
  （名前とスコアの直し方、バナー）だけを「名前とスコア」の節に残した

### ダイスカップの画像を足した（利用者の指摘）

「ダイスを振る」の節に、押すもの（ダイスカップ）の絵が無かった。
`tools/make-shots.mjs` に、**要素のまわりを切り取って近づけて撮る**
仕組みを足し、`docs/images/dicecup.png` を生成するようにした。

## 分担の振り返り

- **何を見つけたか。** wording は「下さい」の表記ゆれのような**表記の
  揺れには強い**が、**語り口の保存と、用語の正確さでは踏み込みすぎた**
  （7 か所を戻した）。重複とスクリーンショットの不足は、
  どちらも**利用者が読んで見つけた**もので、wording は指摘していない
- **見込みと食い違ったのはなぜか。** 担当の編成は見込みどおり。
  ただし「推敲を任せれば読みやすくなる」という見立ては甘かった。
  **文書の構成（重複、絵の不足）は推敲の担当では出てこない**
- **次に同じ規模ならどう組むか。** wording には**表記の統一だけを頼む**。
  構成の重複や、説明に絵が要るかどうかは、**文書を書いた側（main）が
  読み返すか、利用者に見てもらう**ほうが早い。料金は wording が全体の 6%
  （$0.2）で、ここは安い。高いのは main 側で、長い会話を持ち越しているため
