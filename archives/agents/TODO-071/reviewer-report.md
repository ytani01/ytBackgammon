## 要修正

### 1. `src/ytbg/webroot/static/js/lobby.js:68-74` / 縦のスクロールバーが計算の後に出ると、横にはみ出す（確認済み）

- 何が問題か: `avail_w` を `#boards.clientWidth` から取るが、これは**計算した時点の**
  スクロールバーの有無で決まる。倍率を変えるとページの高さが変わり、縦のスクロール
  バーが出たり消えたりする。スクロールバーが出ても `resize` は起きないので計算し直さない
- 実測（スクロールバーを表示する chromium、ボード 2 面、ページを開いた直後）:
  - 1100×1000: 既定の 0.835 ではスクロールバーが無い状態で計算し `--main-scale` = 1.044。
    その後スクロールバーが出て `clientWidth` が 1085 になり、カードの右端が 1091 で
    **6px 横にはみ出し、横のスクロールバーが出た**（`clientHeight` 1000 → 985）。
    `resize` を送ると 1.03 になって収まる
  - 700×1000: 逆に、計算の時点ではスクロールバーがあり 0.641、その後消える。
    収まるが最大ではない（`resize` を送ると 0.656）
  - 1600×700、1000×900 は、計算の前後でスクロールバーの有無が変わらないので正しかった
- なぜ問題か: TODO-071 の要件「縦にも横にもはみ出ない」「最大の値」に反する。
  幅で決まる窓（縦長・正方形に近い窓）を開いた直後に起きる。起きた後に「大きく表示」を
  押すか窓の大きさを変えると直る
- テストで捕まらない理由: headless ではスクロールバーの幅が 0 なので、テストでは
  再現しない（下の 2 とは別の話）

### 2. `tests/browser/lobby.test.mjs:242` / 幅で決まる場合、「余白を残さない」を見ていない（確認済み）

- 根拠（実測）: 上の 700×1000 で、倍率が 0.641（最大ではない）のときも 0.656 のときも

- なぜ問題か: 幅側の最大性がテストで固定されていない。例えば `avail_w` から余計に

## 問題が無かったこと（確認済み）

- **ちらつき・振動:** `fit_main()` は `resize` と `show_main()` からしか呼ばれず、
  `--main-scale` の変更は `resize` を起こさない。ループにならない。1 の件は
  「1 回だけずれた値で止まる」で、繰り返し変わることは無い
- **h1・h3・パディング:** 1600×700・1000×900・1280×720 で、カードの下端はウィンドウの
  下端の 8〜9px 上（body の margin の分と切り捨ての分）。`offsetHeight` の丸めの差は
  0.5px 未満だった
- **h3 が折り返す狭い幅:** 340px 以下で h3 が 27px → 52px になるが、その幅では幅で
  倍率が決まり、高さに余りがあるのではみ出さない。高さで決まるほど低い窓（およそ
  高さ 310px 以下）と重なったときだけ効く。小さいボード（450px 固定）が横にはみ出すのは
  この変更の前からで、範囲外
- **フォントの読み込み:** `lobby.html` はウェブフォントを読まない（font awesome も無い）
  ので、読み込み後に h1・h3 の高さが変わる経路は無い
- **スマホ（`initial-scale=0.4` の viewport）:** playwright の `isMobile`（412×915）で、
  レイアウトの幅は 1030px、倍率 0.976 で幅に収まった。実機の URL バーの出し入れで
  `resize` が続けて起きたときの挙動は**未確認**
- **負の値:** 高さが極端に小さいと `scale` が負になり `scale()` が反転するので、
  `Math.max(..., 0.1)` は要る
- **テストの揺れ:** `setViewportSize` のあと `wait_for` で待つので、`resize` の届く
  時機では落ちない。高さで決まる段は、前の段の倍率のままでは条件を満たさない
  （1280×720 → 1600×700 は下にはみ出す、700 幅の 0.656 → 1280×720 は下に余白が残る）
- **規約・範囲:** 変更は依頼の 5 ファイルだけ。Developer.md に TODO 番号は無く、
  CLAUDE.md の説明は他の行と同じ書き方。コメントは「端数で 1px はみ出さないように」
  「一番上までスクロールした状態で収まるように」など理由を書いている（5 を除く）
