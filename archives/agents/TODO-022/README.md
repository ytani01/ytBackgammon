  絵柄を決めるのに画像を見て作り直す往復が要るので、main が持つほうが速い

  実装した本人は「`<link>` を足したのだから要求されないはず」で済ませて
  しまうので、実プロセスのアクセスログを見る役を分けた
- **reviewer は入れない** — 分岐や条件式が変わらない
