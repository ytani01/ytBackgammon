## 問題なしと確認したもの

- `dst_points()` / `dice_for_move()` のループ化: 2〜4 個の目それぞれで
  元の入れ子・打ち切り条件と一致（上記トレースで確認）。
- `calc_gammon()` の三項演算子化: 分岐の中身は元の if/else と同一。

  `PlayerName` は「生成→生成」から「生成→set→on→生成→set→on」へ
  変わっても副作用に差は出ない。
- `inverse()` の `180 * player`: player 0 → 0、player 1 → 180 で
  元の if/else と一致。

  （`transform` と `zIndex`）を触るだけなので、呼び出し順を入れ替えても
  結果は変わらない（`ui/base.js` で確認）。
