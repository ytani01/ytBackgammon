# TODO-011 の分担

## 分担

| 担当 | 見たもの |
|------|----------|
| main | 実装（`hist_ent2str()` の書式、`save_data()` / `load_data()` の例外） |
| verifier | 保存ファイルの中身が変わらないこと、ruff / mypy / pytest |
| reviewer | 例外を絞ったことの妥当性、書式の置き換えで意味が変わっていないか |

## この分担にした理由

- **実装は main。** 書式の機械的な置き換えが主で、`hist_ent2str()` の 1 関数と
  `except` 2 箇所に閉じている。実装の担当を分けるほどの規模ではない
- **確認は verifier に分ける。** この項目の要は「保存ファイルの中身が
  1 バイトも変わらない」こと。実装した本人は「変わらないはず」で済ませて
  しまうので、**変更前後の出力を実際に取って比べる**ところを別の目に任せる。
  main も実データ 62 エントリで比べたが、`playername` が空文字列のものしか
  無く、日本語や引用符を含む場合を見ていない
- **レビューも入れる。** `except Exception` を絞ると、**今まで握りつぶして
  いた例外が上へ抜ける**。これは挙動の変化なので、「何を拾って何を落とすか」が
  妥当かを見る担当を、確認とは別に置く
